꼬순내 분식 개인정보 처리방침

시행일: 2026년 11월 14일

꼬순내 분식(이하 "게임")은 이용자의 개인정보를 수집하지 않습니다.

1. 수집하는 정보

없습니다. 게임에는 회원 가입과 로그인이 없고, 이름·연락처·위치·기기 식별자 같은 정보를 묻거나 가져가지 않습니다. 광고와 이용 분석 도구도 넣지 않았습니다.

2. 게임 진행 내용의 저장

가게 이름, 동물 친구 이름, 가게 꾸밈, 코인, 직접 만든 메뉴, 적어 둔 의견은 이용자의 기기 안에만 저장됩니다. 개발자나 다른 곳으로 보내지 않습니다.

3. 이용자가 직접 보내는 것

다음 내용은 이용자가 버튼을 눌러 직접 보낼 때만 기기 밖으로 나갑니다. 받는 사람도 이용자가 고릅니다.

  • 초대장: 가게 이름, 레벨, 가게 꾸밈, 동물 친구의 종류·이름·옷, 직접 만든 메뉴의 이름과 그림이 링크에 담깁니다. 코인과 적어 둔 의견은 담기지 않습니다.
  • 백업 코드: 가게 전체 내용이 담깁니다. 이용자가 스스로 보관하는 용도입니다.
  • 의견 모아서 보내기: 이용자가 적어 둔 의견이 담깁니다.

4. 웹 버전의 접속 기록

웹 버전은 GitHub Pages에서 제공됩니다. 웹 페이지를 열 때 GitHub가 접속 기록(IP 주소 등)을 남길 수 있으며, 이는 GitHub의 개인정보 처리방침을 따릅니다. 개발자는 이 기록을 받거나 보지 않습니다.

5. 어린이

게임은 누구에게서도 개인정보를 수집하지 않으며, 어린이도 같습니다.

6. 저장된 내용 지우기

게임 안 설정의 "처음부터 다시 하기"를 누르거나 앱을 지우면(웹 버전은 브라우저의 사이트 데이터를 지우면) 기기에 저장된 내용이 모두 사라집니다.

7. 방침이 바뀔 때

이 방침이 바뀌면 이 페이지에 바뀐 내용과 시행일을 적습니다.

8. 문의

앱 스토어의 게임 페이지에 적힌 개발자 연락처로 문의해 주세요.
