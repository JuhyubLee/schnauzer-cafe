꼬순내 분식 개인정보 처리방침

시행일: 2026년 11월 15일 (최신 모습 공유와 신고 내용을 더했습니다)

꼬순내 분식(이하 "게임")은 회원 가입과 로그인이 없고, 이름·연락처·위치·기기 식별자·광고 식별자를 묻거나 가져가지 않습니다. 광고와 이용 분석 도구도 넣지 않았습니다. 이용자가 "최신 모습 공유"를 켜거나 다른 가게를 신고할 때에만 아래에 적은 내용이 서버로 갑니다.

1. 기기 안에만 저장하는 것

가게 이름, 동물 친구 이름, 가게 꾸밈, 코인, 직접 만든 메뉴, 적어 둔 의견, 다녀온 가게와 차단한 가게 목록은 이용자의 기기 안에 저장됩니다.

벽 액자에 걸려고 고른 사진은 기기 안에서 작은 그림(가로 22칸, 세로 18칸)으로 줄여 저장합니다. 원본 사진은 저장하지 않고, 사진 보관함의 다른 사진은 읽지 않습니다. 액자 사진은 서버로 보내지 않습니다.

2. "최신 모습 공유"를 켰을 때 서버에 올라가는 것

놀러 가기에서 "최신 모습 공유"를 켜면, 초대장을 받은 사람이 올 때마다 그때의 가게 모습을 볼 수 있도록 다음 내용이 서버에 올라가고 가게를 고칠 때마다 새로 올라갑니다. 켜지 않으면 올라가지 않습니다.

  • 가게 번호(게임이 무작위로 만든 글자. 사람이나 기기를 가리키지 않습니다)
  • 가게 이름, 레벨, 가구·바닥·벽지 배치
  • 동물 친구의 종류, 이름, 입은 옷
  • 직접 만든 메뉴의 이름과 그림

코인, 적어 둔 의견, 액자 사진은 올라가지 않습니다. 올라간 가게 모습은 그 가게의 초대장을 받은 사람만 볼 수 있고, 목록이나 검색으로 공개되지 않습니다.

보관 기간: "최신 모습 공유"를 끄거나 설정에서 "처음부터 다시 하기"를 누르면 서버에서 바로 지웁니다. 앱만 지우는 등 그대로 둔 가게 모습은 마지막으로 고친 날부터 180일이 지나면 지웁니다.

3. 신고할 때 서버로 가는 것

구경 중인 가게를 신고하면 적은 신고 사유, 신고할 때 보고 있던 그 가게의 모습, 신고한 쪽의 가게 번호가 서버로 가고 운영자에게 알림이 갑니다. 운영자가 확인해서 욕설이나 불쾌한 내용이 있으면 그 가게를 가립니다. 신고 기록은 1년이 지나면 지웁니다.

4. 이용자가 직접 보내는 것

다음 내용은 이용자가 버튼을 눌러 직접 보낼 때만 기기 밖으로 나갑니다. 받는 사람도 이용자가 고릅니다.

  • 초대장: 가게 번호, 가게 이름, 레벨, 가게 꾸밈, 동물 친구의 종류·이름·옷, 직접 만든 메뉴의 이름과 그림이 링크에 담깁니다. 코인, 적어 둔 의견, 액자 사진은 담기지 않습니다.
  • 백업 코드: 가게 전체 내용이 담깁니다. 액자 사진(줄인 그림)과, 서버에 올린 가게 모습을 고칠 때 쓰는 열쇠도 들어 있습니다. 이용자가 스스로 보관하는 용도이니 남에게 주지 마세요.
  • 의견 모아서 보내기: 이용자가 적어 둔 의견이 담깁니다.

5. 서버와 접속 기록

가게 모습과 신고는 Supabase(Supabase, Inc.)의 서울 지역 서버에 보관합니다. 게임이 서버와 주고받을 때 Supabase가 접속 기록(IP 주소 등)을 남길 수 있으며, 운영자는 이 기록으로 이용자를 알아내려 하지 않습니다.

웹 버전은 GitHub Pages에서 제공됩니다. 웹 페이지를 열 때 GitHub가 접속 기록(IP 주소 등)을 남길 수 있으며, 이는 GitHub의 개인정보 처리방침을 따릅니다. 운영자는 이 기록을 받거나 보지 않습니다.

6. 올리면 안 되는 것

가게 이름, 동물 친구 이름, 메뉴 이름과 그림에 욕설이나 남을 불쾌하게 하는 내용을 넣어 공유하면 안 됩니다. 욕설이 든 이름은 서버가 받지 않고, 신고된 가게는 운영자가 확인해서 다른 사람에게 보이지 않게 가립니다. 본인이나 다른 사람의 실제 이름·연락처 같은 정보를 가게 이름 등에 적지 마세요.

7. 어린이

게임은 나이를 묻지 않으며, 어린이에게서도 위에 적은 것 말고는 아무 정보도 받지 않습니다.

8. 지우는 방법

  • 서버에 올린 가게 모습: 놀러 가기의 "공유 끄고 서버에서 지우기"를 누르면 바로 지워집니다.
  • 기기에 저장된 내용: 설정의 "처음부터 다시 하기"를 누르거나 앱을 지우면(웹 버전은 브라우저의 사이트 데이터를 지우면) 사라집니다. "처음부터 다시 하기"는 서버에 올린 가게 모습도 함께 지웁니다.
  • 그 밖에 지워 달라는 요청은 아래 문의처로 가게 번호나 가게 이름을 알려 주시면 처리합니다.

9. 방침이 바뀔 때

이 방침이 바뀌면 이 페이지에 바뀐 내용과 시행일을 적습니다.
